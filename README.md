# Ink Tattoo School — Build 1

Build 1 establishes the visual system and first-pass homepage for the Ink Tattoo School site.

## Included
- Next.js App Router project shell
- Responsive header and navigation
- High-impact hero section
- Program stats
- Core program pillars
- 12-week curriculum teaser
- Tuition section
- Admissions CTA
- Required educational-program disclosure
- Responsive mobile layout
- Reduced-motion accessibility support

## Run locally
```bash
npm install
npm run dev
```
